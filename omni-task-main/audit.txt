Techniczne SEO2.1 Problem duplikatu www / non-www — KRYTYCZNYTo najpoważniejszy problem techniczny strony. Oba adresy działają równolegle i zwracają identyczną treść:https://omnitask.pl — zwraca HTTP 200https://www.omnitask.pl — zwraca HTTP 200 (brak przekierowania!)Tagi canonical wskazują na wersję www, ale brak faktycznego przekierowania powoduje, że Google może indeksować obie wersje jako osobne strony. Robotnicza reguła "canonical wins over redirect" działa jedynie przy prawidłowej konfiguracji — tutaj canonical i dostępność kolidują.ZALECANA NAPRAWA:W konfiguracji nginx dodaj przekierowanie 301 z non-www na www:server { listen 443 ssl; server_name omnitask.pl; return 301 https://www.omnitask.pl$request_uri; }2.2 Plik robots.txt✅ OKUser-Agent: * / Allow: / / Disallow: /api/ — poprawna konfiguracja, katalog API zablokowany⚠ UWAGASitemap wskazuje na https://www.omnitask.pl/sitemap.xml — upewnij się, że oba warianty URL (www/non-www) wskazują na tę samą mapę2.3 Mapa witryny (sitemap.xml)Mapa witryny zawiera tylko 5 URL-i, co jest bardzo małą liczbą.
